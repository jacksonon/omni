会话检查点（/rewind）

每轮对话自动快照工作区修改文件；回滚文件到该回合状态（对话保留）。列表附与当前工作区的差异。

设置

通用

会话运行的基础行为。

权限级别

控制执行命令前的确认策略：safe 在危险操作前询问，ask 全部询问，read 仅只读。

计划模式

只调研并输出实施计划，不直接修改文件。

语言

界面显示语言，保存后立即生效。

并行会话上限

允许同时运行的会话数量（1-16），超过上限时新消息排队等待。

主题

界面配色方案，选择后立即生效并保存。

界面主题

亮色 / 暗色 / 跟随系统（跟随系统时随操作系统深浅色自动切换）。

状态栏

选择显示在输入区域下方的统计字段（同 CLI/TUI 底部统计行）。

模型配置

配置模型的端点、密钥、推理级别与上下文长度——与 omni.json 的 models 字段共享，保存后写入全局配置文件。

已存储模型

当前配置文件（omni.json 的 models 表）中已存储的模型，点击可编辑。

配置的模型

选择要编辑的模型，切换后下方字段同步为该模型的配置。

端点（baseURL）

OpenAI 兼容 API 地址，如 https://api.deepseek.com/v1。

API Key

留空表示沿用配置文件中已保存的密钥。

✓ 已保存到配置文件

思考级别选项（variants）

逗号分隔，如 low,medium,high；模型只支持这些级别。

当前思考级别

默认使用哪一个级别。

上下文长度（context）

模型的上下文窗口大小（token 数），如 128000。
