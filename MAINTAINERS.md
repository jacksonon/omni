# Maintainers

Omni is currently maintained by **one person**. This file is intentionally honest about that:
there is **no maintainer team** and no formal community organization behind the project.
It is a solo effort, which also means the bus factor is **1**.

## Current maintainer

- **Jackson** ([@jacksonon](https://github.com/jacksonon)) — project owner; responsible for all areas (agent core, tools, safety, TUI, Web/Electron, docs, releases).

## Bus factor

**1.** If the sole maintainer becomes unavailable, the project cannot guarantee continued
maintenance, issue triage, or releases. Nothing here prevents that from changing: the code
is [BSD-3-Clause](LICENSE), so anyone is free to fork and continue it.

## Contributors welcome

Contributions of every size are welcome — bug reports, documentation fixes, small patches,
and larger features. See [`CONTRIBUTING.md`](CONTRIBUTING.md) to get started and
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) for what we expect from participants.

If you contribute regularly and would like to help maintain the project, please open an
issue and say so. Growing the maintainer list is a goal, not a threat — we would rather
raise the bus factor above 1 than stay here.
